# Novelty Boundary Map

## Crowded Territory

- Generic neural scaling laws.
- Generic robot foundation model scaling.
- Bigger robot datasets.
- Generic uncertainty or conformal risk filtering.
- Benchmark-only contribution.

## Claimed Boundary

Scale-law exceptions in robotics audits cases where average scaling metrics improve while embodied failure-boundary metrics regress: rare-failure recall, contact-boundary error, unsafe commitment, overtrust, shortcut reliance, embodiment mismatch, and recovery scarcity.

## What Would Falsify The Claim

If a scaled robot model, conformal risk filter, or ensemble uncertainty gate matches the proposed audit on success, rare-failure recall, contact-boundary error, unsafe commitment, overtrust, and ablation robustness under external robot validation, the paper should be killed.
